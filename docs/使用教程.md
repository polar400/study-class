# study class 使用教程

适用版本：v1.0.11，Windows x64。普通使用者不需要安装 Go。请使用本人或已获明确授权的账号，并先阅读随包许可和免责声明。

## 1. 下载并完整解压

1. 打开 [最新版本页面](https://github.com/polar400/study-class/releases/latest)。
2. 在附件中下载 `study-class-v1.0.11-windows-amd64.zip`。
3. 右键 ZIP，选择“全部解压”，解压到自己有写入权限的文件夹。不要在压缩软件内部直接运行。
4. 解压后的顶层应只有 `启动.bat`、`config.json`、`app/` 和 `docs/` 四项。

GitHub 自动生成的“Source code (zip)”和“Source code (tar.gz)”面向开发者，里面没有可直接使用的成品 EXE。普通使用者请选择文件名包含 `windows-amd64` 的包。

## 2. 填写并保存账号

1. 找到与 `启动.bat` 同一层的 `config.json`。不要在 `app/` 中另建配置。
2. 右键文件，选择“打开方式 → 记事本”。也可双击 `启动.bat` 后选择“打开配置”。
3. 将 `username` 后面的“请填写已授权学号”改为学号，将 `password` 后面的“请填写密码”改为密码。
4. 保存时使用 UTF-8 编码，文件名保持 `config.json`，不要变成 `config.json.txt`。
5. 保留英文双引号、冒号和逗号，最后一项后面不要多加逗号。

第一次使用只需修改学号和密码。当前站点地址保留 `https://bxait.haiqikeji.com`；`authorization` 和 `cookie` 保持空字符串，不需要从浏览器复制。

如果密码包含双引号 `"`，JSON 中须写为 `\"`；如果包含反斜杠 `\`，须写为 `\\`。不要将真实密码粘贴到公开的在线 JSON 工具、截图、Issue 或聊天记录中。

### 单账号配置示例

以下全部是占位内容，请替换后再使用：

```json
{
  "global": {
    "server": "127.0.0.1:10087",
    "limit": 3,
    "per_account_limit": 1,
    "page_size": 32,
    "heartbeat_seconds": 30,
    "timeout_seconds": 30,
    "course_ids": [],
    "include_ended": false
  },
  "users": [
    {
      "base_url": "https://bxait.haiqikeji.com",
      "username": "请填写已授权学号",
      "password": "请填写密码",
      "authorization": "",
      "cookie": ""
    }
  ]
}
```

### 多账号配置示例

在 `users` 数组中增加账号对象，相邻对象之间保留逗号。这里只填写本人或已获明确授权的账号：

```json
{
  "global": {
    "server": "127.0.0.1:10087",
    "limit": 3,
    "per_account_limit": 1,
    "page_size": 32,
    "heartbeat_seconds": 30,
    "timeout_seconds": 30,
    "course_ids": [],
    "include_ended": false
  },
  "users": [
    {
      "base_url": "https://bxait.haiqikeji.com",
      "username": "请填写第一个已授权学号",
      "password": "请填写第一个密码",
      "authorization": "",
      "cookie": ""
    },
    {
      "base_url": "https://bxait.haiqikeji.com",
      "username": "请填写第二个已授权学号",
      "password": "请填写第二个密码",
      "authorization": "",
      "cookie": ""
    }
  ]
}
```

### 字段说明

| 字段 | 含义与建议 |
|---|---|
| `users[].base_url` | 账号所属平台地址；当前适配站点保留默认值。 |
| `users[].username` | 本人或已获授权的学号。 |
| `users[].password` | 对应密码，只保存在自己的本机配置中。 |
| `users[].authorization`、`cookie` | 可选授权会话字段，普通账号密码使用方式保持为空。 |
| `global.server` | 本机状态服务地址，默认 `127.0.0.1:10087`；不要改成对外监听地址。 |
| `global.limit` | 全局同时处理课程数上限，正整数，默认 3。 |
| `global.per_account_limit` | 每个账号同时处理课程数上限，正整数，默认 1，同时受全局限制。 |
| `global.page_size` | 课程分页大小，默认 32，通常无需修改。 |
| `global.heartbeat_seconds` | 提交间隔，默认 30 秒，建议保留。 |
| `global.timeout_seconds` | 网络请求超时，默认 30 秒。 |
| `global.course_ids` | 只处理指定课程 ID；默认空数组，不额外按 ID 筛选。 |
| `global.include_ended` | 是否包含截止日期已过课程，默认 `false`。 |

多账号和多课程并发是客户端调度能力，不保证平台允许或认可任意并发。第一次使用建议保持默认并发，先检查配置和账号。

## 3. 先检查，再运行

双击 `启动.bat`。菜单中提供以下操作，按屏幕显示选择即可：

| 菜单操作 | 用途 |
|---|---|
| 打开配置 | 用本机记事本打开顶层 `config.json`。 |
| 检查 | 登录并只读检查课程和章节，不启动学习会话或提交学时；会访问平台。 |
| 前台运行 | 在可见窗口运行；需要验证码时按提示处理。 |
| 后台运行 | 隐藏窗口运行；不适合需要输入验证码的情况。 |
| 打开状态页 | 在本机浏览器打开配置中的状态服务地址。 |
| 停止 | 请求本程序结束会话并退出，之后再关闭相关窗口。 |
| 预览 | 查看保留的 POLAR Logo、study class 名称和日志示例，不连接平台。 |
| 打开教程 | 打开随包的本地 HTML 教程，不需要联网。 |
| 退出 | 退出启动菜单；后台进程需另用“停止”操作结束。 |

建议首次选择“检查”。若提示配置或账号错误，先修正后再继续；检查正常后选择“前台运行”。开始时不需要同时开启多个程序副本。

前台运行期间保留运行窗口，不要直接点击关闭。需要结束时可在另一份启动菜单中选择“停止”；程序响应后再关闭窗口。后台运行时，关闭启动菜单不会自动停止后台进程。

任务处理结束后，本机状态服务可能继续保留供查看。需要完全退出或释放端口时使用“停止”。

## 4. 查看状态和理解进度

默认状态页是 [http://127.0.0.1:10087](http://127.0.0.1:10087)。它属于运行程序的这台电脑，不需要连接发布者电脑。程序未运行时，页面打不开是正常情况。

- “当前进度”来自平台回读。平台可能在活动会话中较长时间不刷新，结束会话后才返回新记录。
- “计时进度”按视频时长、平台已有百分比和实际经过时间独立显示。续学从平台已有百分比开始，每增加 1% 输出一次，同值不重复。
- 计时进度到 100% 时仍显示“等待平台确认”。只有平台回读确认完成后，程序才进入下一视频；失败会暂停该课程。
- 同步网络请求阻塞时，计时显示也可能延后，恢复后补齐已经过的计时整数。
- 蓝色 INFO 表示普通信息或等待；绿色 INFO 表示平台确认或已完成跳过；红色 ERROR 表示失败或暂停。颜色仅用于标签，日志文件保持纯文本。

本机计时或预览示例不能证明平台实际保存学时。状态页继续显示平台进度。视频进度完成也不代表作业、考试、学分或结课达标。

## 5. 更新版本与文件位置

更新时先用旧版的停止入口停止旧进程，再把新版解压到新文件夹。旧版 `config.json` 的配置结构仍可沿用，确认属于自己的配置后，将它复制到新版与 `启动.bat` 同层的位置；不要覆盖新版 `app/` 和 `docs/`。

只迁移自己的配置即可。缓存与 Windows 用户绑定，换电脑或换 Windows 用户时不要依赖复制旧缓存；程序可按配置重新认证。

运行后会生成：

- `app/logs/`：本机日志。
- `app/state/`：当前 Windows 用户保护的会话缓存。
- `app/reports/`：本机状态记录。

这些目录、个人配置和备份都不要上传。发布包中不包含发布者的真实账号、缓存或运行记录。

## 6. 常见问题

### 提示配置格式错误，或保存后没有变化

确认编辑的是解压后顶层的 `config.json`，已经保存，且文件扩展名不是 `.json.txt`。检查英文双引号、逗号、括号及密码中的转义字符；可对照单账号示例恢复结构。排查时不要公开带密码的配置或截图。

### 账号或密码不正确

确认填写的是对应平台的学号和密码，账号属于本人或已获授权。先在平台正常页面核对是否能够登录；有验证码时先选择“检查”或“前台运行”并按提示输入，后台隐藏运行不能代替手动处理验证码。不要把认证失败当作学习成功。

### 状态端口被占用，或状态页显示旧版本

通常是旧程序仍在运行。先用旧版或新版菜单的“停止”结束对应状态服务，再启动一个新版副本。若确实需要修改 `global.server`，应保持 `127.0.0.1` 本机地址并为不同实例选择不同端口；菜单和程序应读取同一份配置。

### 很久没有新的百分比

“当前进度”依赖平台回读，可能延后刷新；“计时进度”也可能因同步网络请求阻塞而延后。查看最近一条状态是否为等待或错误，不要把没有新输出当成已经完成，也不要用本机计时替代平台确认。程序失败时会暂停该课程。

### 关闭菜单后程序为什么还在，如何停止

“后台运行”创建的是独立进程。再次双击 `启动.bat`，选择“停止”。若无法联系服务，确认程序是否已退出，以及配置中的端口是否与正在运行的实例一致。不要连续启动多个副本来尝试停止旧任务。

### 程序无法启动或下载不完整

重新下载 Windows x64 成品包并完整解压，确认 `app/study-class.exe` 存在，目录有写入权限。如果系统安全软件显示拦截或警告，应先核对发布地址、附件校验值和提示内容，按学校或设备管理要求处理；不要关闭防火墙或关闭系统安全防护。
