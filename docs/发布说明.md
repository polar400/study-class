# study class v1.0.11

支持西工商课程学习。适用于 Windows x64。

## 下载

普通使用者下载 `study-class-v1.0.11-windows-amd64.zip`，完整解压后双击 `启动.bat`。程序无需安装 Go。

开发者可下载 `study-class-v1.0.11-source.zip`；源码按 `src/`、`docs/`、`scripts/` 归类，构建需要 Windows 和 Go 1.26 或更高版本。

## 本版调整

- 项目显示名称改为 study class，仓库为 [polar400/study-class](https://github.com/polar400/study-class)，作者 POLAR 字符 Logo 原样保留，Logo 下方显示仓库网址。
- 下载包顶层精简为 `启动.bat`、`config.json`、`app/`、`docs/`，统一菜单保留检查、前台与后台运行、状态页、停止、预览及帮助。
- 补齐单账号、多账号配置示例、字段说明、迁移步骤和常见问题；提供本地离线 HTML 教程。
- 程序运行数据收在 `app/`，配置仍位于顶层；原有学习流程、认证、配置结构及平台完成判断沿用现有实现。

## 使用说明

先填写本人或已获明确授权的配置，选择“检查”，确认无误后再运行。已发布的 v1.0.10 保留供回退；升级前先停止旧版，并只将自己的 `config.json` 迁移到新版顶层。

“计时进度”与平台“当前进度”分开显示，计时100%仍等待平台确认；当前视频经平台回读确认后才继续下一视频，失败暂停该课程。不保证平台实际认可学习记录，也不保证成绩、作业、考试或结课结果。
