# POLAR

适用于 Windows x64 的课程学习辅助客户端。下载 ZIP、解压、填写自己的账号配置后，可通过 BAT 启动。程序与状态页在使用者自己的电脑运行，无需连接发布者的电脑。

## 下载与运行

1. 从本仓库的 Releases 下载 `POLAR-v1.0.10-windows-amd64.zip`，解压到自己有写入权限的目录。
2. 编辑解压目录中的 `config.json`，填写本人或已获明确授权的账号和密码。源码仓库使用者可先将 `config.example.json` 复制并改名为 `config.json`。
3. 先双击 `检查.bat` 做登录、课程和章节的只读检查。
4. 需要运行时双击 `运行.bat`。如需隐藏窗口，可使用 `后台运行.bat`；出现验证码时需要在前台处理。
5. 在同一台电脑访问 `http://127.0.0.1:10087` 查看状态。用 `结束.bat` 或状态页按钮停止本程序。

运行 EXE 不需要安装 Go。请勿将自己的配置、缓存、日志或备份上传至 GitHub。

## 配置

`users` 数组可放多个账号。每项填写 `base_url`、`username`、`password`；已有授权会话也可使用 `authorization` 和 `cookie` 字段，但不要公开这些值。

- 当前已适配的目标站点：`https://bxait.haiqikeji.com`。其他站点未获得通用兼容保证。
- `global.limit`：全局并发上限，正整数。
- `global.per_account_limit`：每账号课程并发上限，正整数。
- `global.course_ids`：只运行指定课程ID；空数组表示不按ID额外筛选。
- `global.include_ended`：是否包含截止日期已过的课程，默认false。
- `global.heartbeat_seconds`：提交间隔，默认30秒。
- `global.server`：本机状态页地址，默认 `127.0.0.1:10087`。

源码中提供的账号及预览账号均为示例，不包含发布者的真实账号或密码。会话缓存在运行者自己的 `state` 目录，用 Windows DPAPI 加密。

## 运行规则与实际限制

多门课程可并行，每门课程内部按目录顺序，从第一个未完成的视频继续。已完成视频静默跳过；当前视频只有经平台回读确认100%后才进入下一节。出错暂停该课程，其他课程继续。

控制台区分两种进度：“当前进度”来自平台回读，只有平台真实整数进度增长至少1%时才输出新的百分比；“计时进度”是按视频时长和实际经过时间计算的本地展示，续学时从平台已有百分比开始，每增加1%输出一次，同值不重复。计时值不会改写平台进度，也不作为完成或跳到下一节的依据。

普通信息显示蓝色 INFO，平台确认完成或已完成跳过显示绿色 INFO，失败和暂停显示红色 ERROR。计时进度到100%时仍显示蓝色 INFO“等待平台确认”，只有平台回读确认完成后才显示绿色完成结果。颜色仅用于日志标签；不支持颜色的终端及重定向输出使用纯文本，日志文件保持纯文本。可双击 `预览.bat` 查看无需连接平台的示例。

当前目标站点的已知进度接口在测试的活动会话中未持续更新，结束会话后才返回新记录。因此平台“当前进度”可能较长时间没有变化；本机状态页继续显示平台进度。同步网络请求阻塞期间，计时显示也可能延后，恢复后按已经经过的时间补齐计时整数。计时进度达到100%不证明平台保存成功，视频进度完成也不代表作业、考试、成绩或课程结课达标。

本程序使用后台HTTP会话，不解码或播放视频。是否允许该使用方式、如何计入学习记录，由平台规则及服务端决定；本项目不保证规避任何平台限制或账号风险。

## 源码与构建

需要 Windows 和 Go 1.26或更高版本。可运行 `构建.bat`，或自行执行Go测试与构建。构建前脚本会保存根层程序文件的本地备份，最多保留最近5份；`dist` 发布包不在该脚本的备份范围内，替换前需另行保存。源码构建必须保留 `polar-logo.txt`，它由 `go:embed` 编入EXE。

源码包含 `client_test.go`、`console_test.go` 和 `timed_progress_test.go`，分别覆盖本机模拟接口、日志输出及计时进度行为，不需要真实课程账号。这些测试验证代码行为，不证明平台实际认可学习记录。针对个人账号的诊断文件、运行记录和缓存未放入公开仓库。
